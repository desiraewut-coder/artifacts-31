Quiet Ledger Notion / GitHub Pages widget

Upload index.html and the images folder to the ROOT of a GitHub repository.
Settings > Pages > Deploy from a branch > main > /(root).
Embed https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/ in Notion.
Four random images display side-by-side and reshuffle every 2 minutes.
This package contains ONLY the six latest Quiet Ledger illustrations, not the entire artifact collection.
